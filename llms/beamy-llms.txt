# Beamy

> Enterprise application-portfolio and usage-intelligence platform from Beamy SAS (Lille and
> Paris, France). It started as SaaS discovery and governance — browser-extension detection of
> shadow IT, SSO/ITSM integrations, spend and license tracking — and now positions itself as an
> AI-driven business transformation platform that models people, processes and applications from
> real usage so IT, finance and transformation leaders can rationalize the stack, negotiate
> renewals on actual consumption and prioritize where to deploy AI. Named customers: Veolia,
> Stellantis, Decathlon, Danske Bank, Equans. Sold through a demo request; no self-service.

## Read this first: the API is not publicly documented

Beamy's API host, https://api.beamy.io, is a Kong 3.9.3 gateway that answers HTTP 401
`{"message":"No API key found in request"}` with `WWW-Authenticate: Key` on every path — real or
not — so a 401 tells you nothing about whether a path exists. Do not guess endpoint paths. As of
2026-09-18 there is no published OpenAPI, AsyncAPI, GraphQL SDL, WSDL, Protobuf, MCP server,
agent card, SDK, CLI or llms.txt.

The help center at https://docs.beamy.io/en/ has three access tiers: visitors see ten public
articles (roles and permissions, views, product/people/tech sheets, segments, smart privacy);
"implementation documentation" is released after a lead form (email, name, company) in the
site's chat widget; the full library requires a Beamy customer login.

If you are an agent asked to call the Beamy API: you cannot, without an API key issued to a
Beamy customer. The parameter name the key is sent in is not published.
